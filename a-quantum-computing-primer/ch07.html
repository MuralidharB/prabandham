The Universal Pipeline

Flat superposition → oracle → phase-to-amplitude conversion → measure. Every algorithm in this book is an instance of this sentence.

Strip away the specifics of any quantum algorithm and the same skeleton remains. This chapter is the thesis of the book; Parts III–IV are its evidence.

flat superposition  →  oracle / compute  →  phase-to-amplitude conversion  →  measure

notation — teal: amplitude · violet: phase

Stage 1 — Flat superposition

Hadamards across the register produce equal amplitude on all 2ⁿ inputs. Like a diffraction grating illuminated evenly, this stage contains no answer — it prepares a canvas on which interference can paint one.

Stage 2 — Oracle / compute

A reversible computation imprints the problem's structure onto the state — almost always as phase. Grover's oracle flips the sign of the marked item. Shor's modular exponentiation entangles the control register with function values, encoding the period in relative phases. Critically, the standard-basis statistics are still flat after this stage: the answer is written where measurement cannot see it.

Stage 3 — Phase-to-amplitude conversion

The signature move. A carefully chosen unitary makes the phase pattern interfere: components pointing the same way reinforce; opposed components cancel. Grover's diffusion operator and Shor's inverse QFT are the two converters you will study in chapter |1010⟩ — different machinery, identical job. Probability mass flows toward answer-encoding strings.

Stage 4 — Measure

Now, and only now, the blunt instrument falls — onto a distribution the algorithm has spent its whole run sharpening.

Why this shape is forced

Each stage answers a constraint from Part I. Flat superposition exploits the exponential state space (ch. |0010⟩). Phase encoding works because phase is real but statistically invisible (ch. |0101⟩). Conversion is required because measurement only sees magnitudes (ch. |0110⟩). The pipeline isn't a convention — it is the unique shape of an algorithm that respects what quantum mechanics gives and withholds.
