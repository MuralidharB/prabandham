Measurement

Collapse is a blunt instrument. Algorithms succeed by finishing their work before it falls.

Measurement is the interface between the quantum state and classical reality, and it is deliberately unimpressive: measuring an n-qubit register in the standard basis returns one n-bit string, sampled with probability |amplitude|², and collapses the register onto that string. The superposition, the phases, the correlations — gone. Measure again and you get the same string.

The Born rule

Pr[ outcome x ] = | αₓ |²

Note what the rule does not expose: it squares away the phase. Two states whose amplitudes differ only in phase produce identical standard-basis statistics — which is precisely why chapter |0101⟩'s basis-rotation trick is necessary.

Shots and statistics

One measurement is one sample. Real quantum programs run the same circuit many times (“shots”) to estimate the outcome distribution — unless the algorithm has concentrated nearly all amplitude on a single answer, in which case a handful of shots suffice. Good algorithms aim for exactly that concentration.

Choosing the question: measurement bases

Nothing forces the standard basis. Rotating the state before measuring — an H here, a QFT there — is equivalent to asking a different question of the same state. The physical measurement stays blunt; the rotation decides what it is blunt about. This reframing dissolves a common confusion: quantum algorithms don't “read the amplitudes.” They engineer the state so the one question a measurement can answer is the question you wanted asked.

Partial measurement

Measuring only some qubits of an entangled register collapses the rest conditionally: measure one half of a Bell pair and the other half snaps to a definite state. In Shor's algorithm this appears when the function register is (conceptually) measured, leaving the control register in a periodic superposition — the input the inverse QFT needs.

Keep this Measurement gives one sample from |amplitude|² and destroys the rest. All the intelligence of a quantum algorithm is spent making that single blunt sample worth taking.
